使用另一個 Google 帳號創建新的 API Key

⚠️ 重要提醒

如果您剛剛設置了新的 API Key，請確保：

  • 在 Vercel 中設置了 GEMINI_API_KEY 環境變量
  • 勾選了 Production 環境
  • 已經重新部署專案
  • 等待 1-2 分鐘讓部署完成
